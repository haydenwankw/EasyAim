# EasyAim
Creative Code A2 coding prototype. EasyAim.
EasyAim was designed to be a low-computing-stress way for people who want to either train their aim or warm it up without using traditional aim trainers that would take more RAM and take more time to open and close while they are waiting to find a match. 

Thus, the code attached runs on a low-computing-stress engine and environment in Pygame. To run it, you will need to install Python and Pygame, and then copy and paste the code in the EasyAimFinal file into a new Python file or download the file as plaintext  and then run it. I avoided any additional assets like sprites and libraries because it wasn't entirely necessary for the project, as all of the core functions could be coded in using Python and the already integrated Pygame systems. Another upside to this is that it does make it easier on the player as they won't have to install additional materials
