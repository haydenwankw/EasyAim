Project Name
EasyAim

General Information

EasyAim was designed to be a low-computing-stress way for people who want to either train their aim or warm it up without using traditional aim trainers that would take more RAM and take more time to open and close while they are waiting to find a match. I decided to code this specifically because I’ve always liked practicing my aim and getting better because it's something that I enjoy doing, and seeing the results gives me a sense of satisfaction. I’ve personally struggled with traditional aim trainers like AimLabs or Kovak’s because they can take up memory and thus cannot really be used while you have an actual game open. 

Of course, this can be solved with simply getting more RAM, but that’s expensive and can often take time, which sometimes aren’t practical options. So this is more of a passion project for me, as it is related to a pretty big hobby of mine, and it addresses one of my biggest pet peeves when it comes to actually getting better/warming up. Thus, the code attached runs on a low-computing-stress engine and environment in Pygame. 

Technologies used

Pygame version 3.14.7
Python

Features

Targets in various sizes, making it easier and harder to hit
Targets appear and disappear when hit
Targets in various sizes have different points 
The player can see their score and the time left in the top corners of the screen
When the game ends the game will show the scores front and centre for the player to see
